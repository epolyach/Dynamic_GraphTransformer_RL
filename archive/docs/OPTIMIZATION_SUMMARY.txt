================================================================================
HOW TO USE
================================================================================

The changes are already committed and pushed. Future training will automatically
use parallel generation if num_workers > 0 in config.

To verify on new training runs:
  1. Monitor with htop - should see 6-7 cores active
  2. Monitor with nvidia-smi - GPU util should increase to 40-60%
  3. Check epoch times - should be ~3-4x faster

To test different worker counts:
  python scripts/benchmark_parallel_generation.py \
      --config configs/tiny_gpu_512.yaml \
      --batch-size 512 \
      --num-batches 10 \
      --workers 0 4 6 8

To disable parallel generation (for debugging):
  Set num_workers: 0 in config YAML
